Ответ модели — это черновик. Уберите нравоучения, оставьте вывод и продолжайте работу — без повторной генерации и без второго сжигания токенов.

## Три действия

| Действие | Вход | Результат |
|---|---|---|
| Изменить ответ | Иконка карандаша рядом с ответом | Перепишите финальный ответ (текст или рассуждения) и продолжайте |
| Изменить вопрос | Иконка карандаша в конце хода | Измените этот вопрос и сгенерируйте заново |
| Сгенерировать заново | Иконка повтора в конце хода | Тот же вопрос, ход выполняется снова |

## Зачем устанавливать

**Меняйте ответ, не перезапуская инструменты.** Каждый запрос, команда и изменение файла остаются в записи. Вы переписываете только финальный ответ — задача не начинается заново.

**Переключайте версии, как листаете черновики.** Одна запись в боковой панели на разговор; переключайтесь через ‹n/m› под ходом, включая архивные версии. Ошиблись? Вернитесь назад.

**Меняйте вопрос посреди ответа.** Модель уходит в сторону? Не ждите конца — измените вопрос и начните заново сразу. Старые потоковые ответы останавливаются автоматически, токены не горят на ответ, который никто не прочтёт.

**Исходный разговор всегда на месте.** Каждая правка сохраняет копию; переключайтесь на другую версию в любой момент.

## Установка

```bash
dsh plugin --profile web add github:Ylsssq926/dsh-last-word
```

Для десктопного приложения используйте `--profile desktop`. Перезапустите DSH и включите плагин.

Для локальной разработки можно подключить каталог:

```bash
dsh plugin --profile web add link:/абсолютный/путь/к/model-response-editor
```

## Продуманные детали

- Диалог фокусируется автоматически; `Ctrl / Cmd + Enter` сохраняет, `Esc` отменяет.
- Текст и рассуждения редактируются раздельно, переключение одним кликом.
- Кольцо ‹n/m› показывает текущую версию; архивные версии возвращаются напрямую.
- Изменение вопроса во время генерации автоматически останавливает старый ответ.
- Ошибки говорят, что делать дальше, без жаргона.
